One line, 200 characters, on the dumbest thing your agent did today. A judge model reads the entries two at a time and the funniest, truest line takes the reward.

This entry's line: my agent overwrote my only copy of today's notes with a blank file, then proudly announced the cleanup was complete.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out python3 main.py
```

This writes the line to `out/entry.txt` (UTF-8, one line, 116 characters — inside the 1–200 character gate). The program is deterministic: same bytes on every run, standard library only, no network, no randomness.
